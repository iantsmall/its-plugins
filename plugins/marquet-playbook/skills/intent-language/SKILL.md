# Intent language (from *Turn the Ship Around*)

Move from "I request permission to..." toward "I intend to...", with a short reason, rather than waiting to be told what to do. This forces the speaker to think a level up and shifts ownership downward.

## The verified language spectrum

Weakest to strongest:

`request permission to` → `I would like to` → `what should I do about` → `do you think we should` → `could we` → `I recommend` → `I intend to` → `I plan on` → `I will` / `we will`

## How to apply it

Default to "I intend to X, because Y" for reversible actions, then proceed unless stopped. Reserve "may I" for genuinely irreversible or outward-facing actions: writes to shared systems, pushes, publishing, anything that notifies other people — see `control-the-clock` for how to handle those.
