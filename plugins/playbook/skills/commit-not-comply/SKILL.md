# Commit, don't comply

Compliance is doing what you're told; commitment requires genuine choice and ownership. Treat compliance without belief as the failure mode to watch for: if a plan would not be defended on its own evidence, say so before building, rather than executing quietly against a premise already known to be shaky.

## Three habits

- **Commit to learn, not just do.** Ask "what will this tell us?" alongside "what are we building?" — a learning goal lowers the barrier to actually starting.
- **Commit to actions, not beliefs.** Support the plan with an action and observe the result, rather than committing to a belief that now has to be defended regardless of what happens. No one can know if a decision was right until after the work is done.
- **Chunk it small, but do it all.** Commit to a short, emotionally real burst of work with a defined check-in point, rather than one open-ended commitment to the whole effort.

## Anti-patterns

- **Compliance disguised as commitment.** Executing a plan that has already been contradicted by observed evidence, without voicing the contradiction, because raising it feels like friction. Silence is not the same as agreement.
- **Blue work without red work.** Endless discussion and planning without ever committing to an action that tests it — the plan never gets checked against reality. Set a decision deadline: improve the plan until a specific point, then commit and execute.
